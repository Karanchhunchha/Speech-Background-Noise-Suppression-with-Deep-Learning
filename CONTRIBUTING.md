# Contributing

Short version: this is a single-author MathWorks challenge project,
kept deliberately small and verifiable. If you fork or extend it:

- Run `run_all_tests()` before changing behaviour; run
  `verify_submission()` before calling anything done.
- Keep the pipeline toolbox-free beyond Deep Learning Toolbox (and
  optional Signal Processing Toolbox cross-checks): the hand-written
  STFT/ISTFT and metrics are the point, and the tests pin them against
  references.
- Never edit numbers in `reports/` by hand — they are generated by
  `evaluate_models()` / `merge_evaluation()` and the README table by
  `tools/update_readme_results.m`.
- Report results honestly, including the ones that get worse; the
  ablation log in `reports/ablation.md` is the model for how changes
  are justified here.
